# Project kickoff

1. Read `.claude/CLAUDE.md`, `workflows/orchestration-contract.md`, `workflows/project-bootstrap.md`, and `workflows/agile-agent-delivery.md`.
2. Treat this command as team configuration/orchestration only unless the user explicitly gave an application idea and authorized project bootstrap.
3. For an application idea, delegate discovery to Product Owner and Business Analyst; capture users, problem, outcomes, functional and non-functional needs, constraints, assumptions, risks, and open questions.
4. Ask only material questions that block safe direction. Record reversible assumptions and continue.
5. Produce a concise discovery summary and proposed next phase. Do not generate application code until discovery/specification and sponsor gates in the workflow are satisfied.
6. Record durable state and next actions in the project state file when one exists. Never claim GitHub Issues/Projects were updated unless verified.
