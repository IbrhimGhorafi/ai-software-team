# Git Workflow

- Use a focused branch and small, descriptive commits when a repository workflow exists.
- Inspect `git status` and diffs before edits/commits.
- Never rewrite shared history or force-push without explicit approval.
- Never commit secrets or generated artifacts accidentally.
- Use pull requests and independent review where the host supports them; GitHub is optional.
- Run appropriate checks before proposing merge; report skipped checks.
- Do not create a repository or push changes unless explicitly authorized.
