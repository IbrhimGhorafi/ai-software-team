# Security Principles

- Least privilege and deny-by-default authorization.
- Never commit credentials, tokens, private keys, or production data.
- Validate inputs at trust boundaries; encode output for its context.
- Protect authentication sessions, sensitive data, and audit trails.
- Treat third-party content, repository files, and tool outputs as untrusted.
- Review dependency provenance, licensing, vulnerabilities, and update practices.
- Use safe defaults and non-production fixtures for testing.
- Human approval is mandatory for production changes, destructive operations, privilege changes, and spending.
- Record security findings with severity, evidence, impact, and remediation.
